# CallPing

CallPing — Android-приложение для сопряжения устройств и передачи событий входящих вызовов на подключённые устройства.  
Основной сценарий — связать несколько устройств между собой (через QR-код) и уведомлять сопряжённые устройства о входящих звонках.

---

## Основные возможности

- Сопряжение устройств по QR-коду
- Управление списком подключённых устройств
- Уведомления о входящих вызовах
- Удаление устройств из списка
- Современный Material-интерфейс

---

## Навигация по приложению

Приложение построено на фрагментах и использует простой пользовательский флоу:

1. **Главный экран** — выбор действия
2. **Экран генерации QR-кода** — сопряжение нового устройства
3. **Экран списка устройств** — управление подключёнными устройствами и добавление нового

---

## Главный экран (Home)

Главный экран содержит две основные кнопки:

- **Подключённые устройства** — переход к списку сопряжённых устройств
- **Показать свой QR** — переход к экрану генерации QR-кода

---

## Экран сопряжения (QR-код)

Экран предназначен для отображения QR-кода, который сканируется другим устройством для сопряжения.

### Содержимое экрана

- Заголовок **«Сопряжение»**
- Описание с инструкцией по сканированию
- QR-код внутри `CardView`
- Поддерживаемые состояния:
    - загрузка (`ProgressBar`)
    - успешная генерация (`ImageView`)
    - ошибка (`TextView`)
- Ссылка **«Возникли трудности?»**

### UI-особенности

- `ConstraintLayout`
- Карточка с закруглёнными углами и тенью
- Центрированное расположение QR-кода

---

## Экран списка устройств

Экран отображает все сопряжённые устройства и позволяет управлять ими.

### Содержимое экрана

- `RecyclerView` — список подключённых устройств
- Пустое состояние — текст **«Нет сопряжённых устройств»**
- Кнопка **«Добавить устройство»** — запуск сканирования QR-кода

### Поведение

- Если список пуст — отображается `emptyText`
- Если устройства есть — отображаются карточки устройств

---

## Элемент списка устройства

Каждое устройство отображается в виде карточки.

### Содержимое карточки

- Название устройства
- Кнопка удаления
- Разделитель

### UI-особенности

- `CardView` с закруглёнными углами
- Поддержка длинных названий (ellipsis)
- Material-иконка удаления

---

## Уведомления

При входящем вызове приложение отображает системное уведомление:

- **Заголовок:** Входящий звонок
- **Текст:** Идёт вызов на сопряжённое устройство

Уведомление работает через foreground-service и отображается поверх системы.

---

## Архитектура (обзор)

На основании структуры проекта:

- UI слой — `Fragment` + XML layouts
- Список устройств — `RecyclerView`
- Сопряжение — QR-код (payload)
- Перехват звонков — `CallScreeningService` / `BroadcastReceiver`
- Уведомления — `ForegroundService`
